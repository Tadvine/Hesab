# پروژه اندرویدی دفتر حساب

این پروژه نسخه وب برنامه را داخل WebView بسته‌بندی می‌کند؛ اطلاعات در حافظه محلی برنامه نگهداری می‌شود و برای اجرای خود برنامه اینترنت لازم نیست. چاپ از طریق پنجره چاپ اندروید انجام می‌شود.

## ساخت APK
1. Android Studio را نصب کنید.
2. پوشه `DaftarHesabAndroid` را در Android Studio باز کنید.
3. اجازه دهید Gradle همگام‌سازی شود (برای اولین بار اینترنت و Android SDK لازم است).
4. از منوی **Build > Build APK(s)** استفاده کنید.
5. APK در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نکته
این محیط Android SDK/Gradle و دسترسی دانلود ابزارهای لازم را ندارد؛ بنابراین این فایل، پروژه آماده ساخت است و خود APK کامپایل‌شده نیست. قبل از استفاده عملی، چاپ و نگهداری داده‌ها را روی گوشی آزمایش کنید.

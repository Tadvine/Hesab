# ساخت APK بدون نصب Android Studio

این پروژه یک گردش‌کار GitHub Actions دارد که APK آزمایشی را به‌صورت خودکار می‌سازد.

1. محتوای این پوشه را در یک مخزن GitHub جدید بارگذاری کنید؛ فایل `build.gradle` باید در ریشه مخزن باشد.
2. به زبانه **Actions** بروید.
3. گردش‌کار **Build Android APK** را انتخاب کنید و روی **Run workflow** بزنید. اگر اولین بار است، تأیید فعال‌سازی Actions را انجام دهید.
4. پس از تمام شدن موفق ساخت، همان اجرای workflow را باز کنید.
5. در بخش **Artifacts** فایل `daftar-hesab-apk` را دانلود و از حالت ZIP خارج کنید؛ داخل آن `app-debug.apk` قرار دارد.
6. APK را به گوشی اندروید منتقل و نصب کنید. ممکن است لازم باشد اجازه نصب از این منبع را فعال کنید.

نکته: این APK از نوع debug است و برای نصب شخصی مناسب است. پیش از استفاده روزمره، ذخیره اطلاعات، چاپ و عملکرد آفلاین را آزمایش کنید. داده‌های موجود در نسخه وب به‌طور خودکار به APK منتقل نمی‌شوند مگر اینکه از داده‌ها خروجی/نسخه پشتیبان بگیرید و جداگانه منتقل کنید.
